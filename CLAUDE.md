# Tesseract

Cube smart speaker and alarm clock: a Raspberry Pi Zero 2 W on a custom PCB. The firmware is in
`code/` (Python; overview in `code/README.md`, bring-up steps in `code/BRINGUP.md`). `JOURNAL.md` is
Charlie's personal build journal, so don't edit it unless asked.

## Changelog: keep it up to date

Every session that changes the firmware updates `code/CHANGELOG.md` before finishing: add to today's
entry, or start one from the template at the top of that file. Follow the instructions there: newest
first, plain language, mark what's verified on the Pi vs. only tested, and keep "Open issues" current.
